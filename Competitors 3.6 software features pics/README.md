# Competitors 3.6 software features pics

Screenshots of other UAD 3.6 form-filler products, collected by the owner for a
feature comparison (2026-10-08).

**How to add pictures:** on GitHub, open this folder, then
**Add file → Upload files**, drag the images in (up to 100 at a time) and commit.

Helpful but optional:
- name files by product and screen, e.g. `productname-comp-grid.png`;
- add a `notes.txt` saying what you like or dislike in each one.

**For agents:** these are reference material for *features and workflow only*.
The official specifications (Appendices A-1 to H-1) stay the authority for the
form itself. Do not copy another vendor's code, branding, wording or artwork.
This folder is excluded from the Vercel deploy (`.vercelignore`).
