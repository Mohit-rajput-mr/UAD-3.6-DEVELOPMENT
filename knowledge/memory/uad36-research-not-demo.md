For a real appraisal case the owner wants **no blank section or UAD-validation field**. A fact the case folder lacks is **researched online from public sources** (county assessor/records, listing portals, FEMA flood, census tract, zoning, rent/market data), each value keeping its source (UAD data-source fields), every researched/estimated value listed for the appraiser to confirm, the value opinion derived from the comparables with arithmetic shown. **Demo/placeholder values never go into a deliverable** (only into files named `*_TEST_NOT_A_REPORT.xml` used to test the pipeline).

**Why:** the owner rejected leaving gaps ("you are wrong not to use demo data — do online searches"), while a signed appraisal must not carry invented facts; research with provenance satisfies both. Recorded in the repo as `_work/GOAL.md` standing rule and TASKS T-994.

**How to apply:** start any new case from the TAKEOVER BRIEF (last section of `_work/HANDOFF.md`), then [[uad36-repo-knowledge]]; never log in to or get around a site; owner/borrower names come from the case folder, not people-search.
